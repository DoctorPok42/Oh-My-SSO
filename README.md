# Oh-My-SSO

Oh My SSO - OMSO (Pronouncing "Home So") is a simple, self-hosted, and customizable Single Sign-On (SSO) solution for your applications. It allows you to manage user authentication and authorization across multiple services with ease.

## Documentation

- [Getting started](docs/GETTING-STARTED.md): run it from a fresh clone (local development, Docker Compose on a server), troubleshooting.
- [Production deployment](docs/PRODUCTION.md): Docker Compose on one host (`compose.example.yml`, `.env.example`), OVH KMS or Vault, TLS reverse proxy, first deployment, updates (`scripts/deploy.sh`), backups, checklist.
- [Languages](docs/I18N.md): how the language is chosen, adding a language.
- [Admin console](admin/README.md)
- `make help`: every command, grouped.
